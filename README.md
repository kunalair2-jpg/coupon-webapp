# Local Coupon Finder

A premium web application for discovering local discounts and coupons.

## Features

- **Search by Location & Keyword**: Find deals near you easily.
- **Browse Categories**: Filter by Salons, Parlors, Cafes, Restaurants, Bars, and Shopping.
- **Coupon Redemption**: Reveal discount codes with a single click.
- **Partner Dashboard**: Admin interface for businesses to manage their coupons.
- **Responsive Design**: Looks great on mobile and desktop.
- **Dark Mode**: Premium dark theme by default.

## Getting Started

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Run the development server:
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:3000](http://localhost:3000) with your browser.

## Project Structure

- `src/app`: App Router pages.
- `src/components`: Reusable UI components.
- `src/data`: Mock data for coupons.
